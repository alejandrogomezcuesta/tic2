# Bucles y funciones con Python Turtle

Material para cuatro sesiones de una hora de TIC II, dirigido a 2.º de Bachillerato. Los ejemplos se ejecutan en Thonny y utilizan `turtle`, una biblioteca incluida con Python.

## Sesiones

1. [Sesión 1 · Thonny, Turtle y primeros bucles](sesion-1-thonny-y-primeros-bucles.md)
2. [Sesión 2 · `range`, listas y `enumerate`](sesion-2-range-listas-enumerate.md)
3. [Sesión 3 · Bucles con condiciones y bucles anidados](sesion-3-bucles-anidados.md)
4. [Sesión 4 · Funciones y proyecto integrador](sesion-4-funciones-y-proyecto.md)

Cada sesión contiene una propuesta de distribución del tiempo, teoría breve, código explicado y ejercicios. Al terminar, cada alumno o alumna guarda el entregable indicado en un archivo `.py`.
