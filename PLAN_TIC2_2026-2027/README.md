# TIC2: plan de aula 2026-2027

Plan de 52 sesiones de una hora para 2o de Bachillerato (Andalucia), con clase los lunes y martes, del 22 de septiembre de 2026 al 27 de abril de 2027.

## Como usarlo

- `00_calendario.md`: secuencia global, sesiones, unidades y evaluacion.
- `01_apuntes_teoria.md`: resumen ameno de los ocho temas.
- Cada carpeta mensual contiene una carpeta por fecha lectiva.
- Dentro de cada fecha hay un `sesion.md` con teoria, ejemplos, tiempos, tarea y evidencia de aprendizaje.

## Criterios de organizacion

- Cada sesion esta pensada para 60 minutos: activacion, explicacion breve, practica guiada, reto y cierre.
- Las practicas se plantean con herramientas gratuitas o ya disponibles: Python, navegador, editor de texto, Git/GitHub, Google Drive o alternativa del centro.
- No se solicitan contrasenas, datos personales reales ni publicaciones abiertas del alumnado.
- El festivo indicado como `31/03/2026` queda fuera del curso planificado; se conserva como incidencia en el calendario. Si se pretendia decir `31/03/2027`, esa fecha ya es miercoles y no afecta a las clases de lunes y martes.
