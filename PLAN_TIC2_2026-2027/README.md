# TIC2: plan de aula 2026-2027

Plan de 52 sesiones de una hora para 2o de Bachillerato (Andalucía), con clase los lunes y martes, del 22 de septiembre de 2026 al 27 de abril de 2027.

## Cómo usarlo

- `00_calendario.md`: secuencia global, sesiones, unidades y evaluación.
- `01_apuntes_teoría.md`: resumen ameno de los ocho temas.
- Cada carpeta mensual contiene una carpeta por fecha lectiva.
- Dentro de cada fecha hay un `sesión.md` con teoría, ejemplos, tiempos, tarea y evidencia de aprendizaje.

## Criterios de organización

- Cada sesión está pensada para 60 minutos: activación, explicación breve, práctica guíada, reto y cierre.
- Las prácticas se plantean con herramientas gratuitas o ya disponibles: Python, navegador, editor de texto, Git/GitHub, Google Drive o alternativa del centro.
- No se solicitan contraseñas, datos personales reales ni publicaciones abiertas del alumnado.
- El festivo indicado cómo `31/03/2026` queda fuera del curso planificado; se conserva como incidencia en el calendario. Si se pretendía decir `31/03/2027`, esa fecha ya es miércoles y no afecta a las clases de lunes y martes.
