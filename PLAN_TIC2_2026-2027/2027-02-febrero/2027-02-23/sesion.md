# Sesion 38 - 23/02/2027

**Unidad:** T5, CSS. **Saberes:** TICO.2.B.1.2. **Criterio:** 3.1.

## Teoria breve
CSS separa presentacion y estructura. Una regla combina selector, propiedad y valor. Cascada, especificidad y herencia explican que estilo gana. Usar clases permite reutilizar diseño.

**Enlace original:** [Tema 5, 5.2.2](https://lopegonzalez.es/eso-y-bachillerato/tic-ii-2o-bachillerato/tema-5-la-web/#522-css-el-estilo-de-la-web)

## Desarrollo de 60 minutos
- 0-10: localizar reglas CSS en una pagina.
- 10-20: crear hoja externa y selectores de etiqueta, clase e identificador.
- 20-48: dar estilo a la pagina HTML: tipografia, color, espaciado y responsive basico.
- 48-55: probar ancho movil y contraste.
- 55-60: explicar una decision visual.

## Tarea
Entregar `styles.css` enlazado externamente, con estados hover, layout adaptable y variables de color. Evitar texto sobre fondos ilegibles.

**Evidencia:** pagina antes/despues. **Apoyo:** reglas iniciales. **Ampliacion:** media query.
