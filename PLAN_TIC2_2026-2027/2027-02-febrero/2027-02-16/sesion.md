**Unidad:** T5, arquitectura web. **Saberes:** TICO.2.B.1.1. **Criterio:** 3.1.

## Teoria breve
El navegador es cliente y el servidor aloja recursos y logica. La URL identifica un recurso; DNS traduce dominio a IP; HTTP transporta peticiones y respuestas. Frontend se ejecuta en el cliente y backend en el servidor.

**Enlace original:** [Tema 5, 5.1](https://lopegonzalez.es/eso-y-bachillerato/tic-ii-2o-bachillerato/tema-5-la-web/#51-fundamentos-basicos-de-la-web)

## Desarrollo de 60 minutos
- 0-10: reconstruir una visita web con tarjetas.
- 10-20: explicar URL, DNS, HTTP, cliente y servidor.
- 20-45: equipos dibujan una peticion completa y analizan una URL.
- 45-55: inspeccionar recursos publicos del navegador sin capturar datos privados.
- 55-60: glosario colaborativo.

## Tarea
Diagrama anotado de una peticion web y glosario de diez terminos. Explicar que ocurre al pulsar un enlace.

**Evidencia:** diagrama. **Apoyo:** secuencia numerada. **Ampliacion:** diferenciar GET y POST conceptualmente.
